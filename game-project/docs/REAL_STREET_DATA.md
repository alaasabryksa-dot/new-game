# Real Street Reference Plan — شارع الفيوم، دار السلام

## الوضع الحالي
المسار الموجود في `src/game/track.ts` حلقة لعب إجرائية. المباني والواجهات في `src/game/engine.ts` مولّدة إجرائيًا. لا توجد في المستودع حاليًا قاعدة بيانات موثقة بإحداثيات كل مبنى أو صور واجهات معتمدة. لذلك لا يجوز وصف أي واجهة مولّدة بأنها واجهة محل حقيقي.

## بيانات الطريق المطلوبة
لكل مقطع طريق:
- إحداثيات GPS متتابعة لمركز الطريق، مع اتجاه السير وعدد الحارات والعرض التقريبي.
- نقاط تقاطعات وإشارات ومعابر ومطبات ومواقف ومحطات موثقة.
- اتجاه الحركة وأماكن الوقوف المسموح بها، مع تمييز ما يحتاج تحققًا ميدانيًا.

## بيانات المباني والمحلات المطلوبة
لكل واجهة:
- معرف ثابت، وإحداثيات أو رقم مبنى/قطعة يمكن التحقق منه.
- اسم النشاط كما يظهر على الواجهة، بعد مراجعة بشرية.
- صورة مرجعية أصلية أو مرخصة للاستخدام، وتاريخ جمعها ومصدرها.
- عرض الواجهة وعدد الأدوار والسمات البصرية الملحوظة.
- حالة التحقق: `verified` أو `approximate` أو `procedural`.

## سير الإدخال المقترح
1. جمع خط GPS للطريق والمواقع العامة دون بيانات شخصية للمارة.
2. تقسيم الطريق إلى مقاطع قصيرة قابلة للمراجعة.
3. إدخال أول 200 واجهة ذات أولوية في سجل بيانات منفصل.
4. مراجعة الاسم والموقع والصورة لكل سجل قبل تحويله إلى أصل ثلاثي الأبعاد.
5. استخدام تصميم إجرائي مؤقت فقط للسجلات غير المتحقق منها، مع عدم عرضها كنسخ مطابقة.
6. اختبار التطابق بصريًا على الهاتف من نقاط مشاهدة ثابتة على الطريق.

## معيار القبول
لا تُحسب الواجهة ضمن الواجهات الموثقة إلا إذا اجتمع لها موقع قابل للتحقق ومرجع بصري صالح ومراجعة بشرية. لا تُستنتج أسماء المحلات أو تفاصيلها من التخمين. لا تُستخدم صور الغير دون إذن أو ترخيص مناسب.

## متطلبات الإصدار
- اختبار المسار والمحطات على الهاتف.
- قياس معدل الإطارات واستهلاك الذاكرة على جهاز متوسط.
- تجهيز حزمة Android بعد ثبات نسخة الويب.
- اختبار APK على جهاز فعلي قبل نشر أي إصدار.
