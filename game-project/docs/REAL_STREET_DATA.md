# Real Street Reference Plan — شارع الفيوم، دار السلام

## الوضع الحالي
المسار الموجود في `src/game/track.ts` حلقة لعب إجرائية. المباني والواجهات في `src/game/engine.ts` مولّدة إجرائيًا. لا توجد في المستودع حاليًا قاعدة بيانات موثقة بإحداثيات كل مبنى أو صور واجهات معتمدة. لذلك لا يجوز وصف أي واجهة مولّدة بأنها واجهة محل حقيقي.

## بيانات الطريق المطلوبة
لكل مقطع طريق:
- إحداثيات GPS متتابعة لمركز الطريق، مع اتجاه السير وعدد الحارات والعرض التقريبي.
- نقاط تقاطعات وإشارات ومعابر ومطبات ومواقف ومحطات موثقة.
- اتجاه الحركة وأماكن الوقوف المسموح بها، مع تمييز ما يحتاج تحققًا ميدانيًا.

## بيانات المباني والمحلات المطلوبة
لكل واجهة:
- معرف ثابت، وإحداثيات أو رقم مبنى/قطعة يمكن التحقق منه.
- اسم النشاط كما يظهر على الواجهة، بعد مراجعة بشرية.
- صورة مرجعية أصلية أو مرخصة للاستخدام، وتاريخ جمعها ومصدرها.
- عرض الواجهة وعدد الأدوار والسمات البصرية الملحوظة.
- حالة التحقق: `verified` أو `approximate` أو `procedural`.

## سير الإدخال المقترح
1. جمع خط GPS للطريق والمواقع العامة دون بيانات شخصية للمارة.
2. تقسيم الطريق إلى مقاطع قصيرة قابلة للمراجعة.
3. إدخال أول 200 واجهة ذات أولوية في سجل بيانات منفصل.
4. مراجعة الاسم والموقع والصورة لكل سجل قبل تحويله إلى أصل ثلاثي الأبعاد.
5. استخدام تصميم إجرائي مؤقت فقط للسجلات غير المتحقق منها، مع عدم عرضها كنسخ مطابقة.
6. اختبار التطابق بصريًا على الهاتف من نقاط مشاهدة ثابتة على الطريق.

## معيار القبول
لا تُحسب الواجهة ضمن الواجهات الموثقة إلا إذا اجتمع لها موقع قابل للتحقق ومرجع بصري صالح ومراجعة بشرية. لا تُستنتج أسماء المحلات أو تفاصيلها من التخمين. لا تُستخدم صور الغير دون إذن أو ترخيص مناسب.

## متطلبات الإصدار
- اختبار المسار والمحطات على الهاتف.
- قياس معدل الإطارات واستهلاك الذاكرة على جهاز متوسط.
- تجهيز حزمة Android بعد ثبات نسخة الويب.
- اختبار APK على جهاز فعلي قبل نشر أي إصدار.

## مرجع خرائطي أولي تم العثور عليه — OpenStreetMap

تم العثور على عنصر شارع الفيوم في OpenStreetMap:
- اسم العنصر: Al Fayoum Street / شارع الفيوم.
- OSM way ID: `37195082`.
- النوع: `tertiary`.
- اتجاه السير المسجل: `oneway=yes`؛ يجب التحقق من اتجاهه ميدانيًا قبل ضبط حركة اللعبة.
- عدد العقد المسجلة: 33 عقدة.
- الطول المنشور لهذا العنصر: 1,546 مترًا.
- مركز العنصر المنشور: `29.98454, 31.24776`.
- آخر تعديل ظاهر في صفحة بيانات العنصر: 2025-02-28.
- صفحة العنصر: https://www.openstreetmap.org/way/37195082
- بيانات وصفية وقياس الطول: https://eg.geoview.info/shar_alfywm,37195082w

**حدود التحقق:** هذا عنصر طريق محدد في OSM وليس إثباتًا بعد أنه يغطي كامل المقطع المقصود في اللعبة من كوبري دار السلام حتى الملّف. تقرير محلي عن الشارع يصف هذا الامتداد بنحو 2.2 كم؛ لذلك يوجد فرق بين طول عنصر OSM المنشور (1.546 كم) والامتداد الصحفي (نحو 2.2 كم)، ويجب تتبع الطرق المتصلة ونقاط البداية والنهاية قبل استبدال المسار الإجرائي. لا نمدد الخط أو نضيف إحداثيات تقديرية على أنها GPS حقيقي.

**الترخيص والإسناد:** عند استخدام هندسة OpenStreetMap داخل اللعبة، يجب إظهار إسناد OpenStreetMap والالتزام بترخيص Open Database License (ODbL). صفحة العنصر تعرض قائمة العقد الـ33، لكن يلزم استخراج إحداثياتها بالترتيب وحفظ نسخة من بيانات المصدر وتاريخها قبل بناء مسار اللعبة.


## استخراج هندسة الطريق آليًا

أضيف سكربت قابل لإعادة التشغيل داخل `scripts/fetch-fayoum-osm.mjs`، ويُشغّل من مجلد `game-project` بالأمر:

```bash
npm run osm:fayoum
```

يجلب السكربت هندسة way رقم `37195082` من Overpass، ثم يجلب الطرق المرتبطة بعقدتي البداية والنهاية، ويحفظ البيانات الخام في `src/game/data/fayoum-street-osm.json`. يحتفظ بمعرّفات الطرق والعقد والإحداثيات والوسوم وإسناد OSM وتاريخ الجلب. لا يدمج الطرق تلقائيًا ولا يغيّر مسار اللعب؛ يجب مراجعة أسماء الطرق واتصالها واتجاهاتها وتغطية الامتداد المطلوب قبل اعتمادها.
