# New Game — توكتوك دار السلام

مشروع لعبة قيادة ثلاثية الأبعاد للويب، هدفها تقديم تجربة توكتوك مستوحاة من أسلوب ألعاب القيادة داخل الأحياء المصرية، مع تركيز التطوير على شارع الفيوم الرئيسي في دار السلام.

## الموجود حاليًا
- قيادة توكتوك وتحكم لمس للموبايل، مع كاميرات وألوان مختلفة.
- حركة مرور متنوعة تشمل ملاكي وتاكسي وميكروباص وتوكتوك ونقل.
- إشارات مرور وطوابير مركبات وتغيير حارات ومراعاة مسافة الأمان.
- محطات ركاب، طوابير انتظار متغيرة، صعود ونزول وأجرة لكل راكب.
- وردية وتوصيلات ولفة حرة، مع بنزين وورشة ترقيات وحفظ التقدم.
- مبانٍ وواجهات محلات إجرائية، لافتات عربية وتفاصيل أسطح وأرصفة وأثاث شارع.
- دورة ليل ونهار وأصوات ومؤشرات HUD.

## تشغيل المشروع
من مجلد `game-project`:

```bash
npm ci
npm run dev
```

افتح عنوان التطوير الذي يظهر في الطرفية. لفحص المشروع:

```bash
npm run typecheck
npm test
npm run build
```

## ملاحظة مهمة عن دقة الشارع
المسار والمباني الحالية مولّدة إجرائيًا وليست إعادة بناء مساحية موثقة لشارع الفيوم. أسماء المحطات داخل اللعبة تسميات لعبية، ولا ينبغي اعتبارها مواقع دقيقة أو واجهات محلات حقيقية. يلزم جمع خط سير GPS ومراجع واجهات موثقة ومصرح باستخدامها قبل اعتماد نسخة مطابقة للشارع الفعلي. راجع `game-project/docs/REAL_STREET_DATA.md`.

## حالة أندرويد
المشروع الحالي تطبيق ويب ثلاثي الأبعاد. لم يتم بعد إعداد مشروع Android أصلي أو إصدار APK/AAB نهائي. يلزم إكمال اختبار المتصفح والهاتف ثم إعداد حزمة Android منفصلة والتحقق من التثبيت والأداء على أجهزة فعلية.
